## HAGI_v2 formalization (`Hagi/`)

The `Hagi` library formalizes the mathematical core of the
HAGI_v2 project — the ternary RD-channel causal language model grown
from small domain experts (E:/HAGI_v2). Empirical measurements
(benchmark scores, RMS errors, saturation curves) are not mathematical
statements and are out of scope.

| Module | Formalizes (HAGI_v2 source) |
| --- | --- |
| `Hagi.Hadamard` | Sylvester/Walsh Hadamard matrices of the cross-expert mixer (`src/hagi/model/merge.py`, GROWING_HYPOTHESIS.md Part V): `H * Hᵀ = 2^k • 1`, so `H/√2^k` is orthonormal; every entry ±1 — uniform mixing, no blind channels. |
| `Hagi.Kronecker` | Kronecker products preserve (conjugate-)orthonormality — the algebra behind the recursive/local Hadamard mixer `Q = H_{g_k} ⊗ ⋯ ⊗ H_{g_1}` (Part VI) and the DFT-3 Kronecker recursion. |
| `Hagi.DFT3` | The ternary DFT-3 (F₃) mixer of the recursive growth cycle (README "Growth cycle algorithm"): `ω = e^{2πi/3}`, the character `χ₃`, orthogonality of nontrivial characters on `(ZMod 3)^k`; the k-fold mixer `F₃ᵏ` is unitary with all entries of modulus `1/√(3^k)`. |
| `Hagi.BlockDiag` | Block-diagonal merge (`GROWING_HYPOTHESIS.md "Механизм"`): at step 0 the merged linear layer `diag(W₁,…,W_N)` computes exactly the N independent experts. |
| `Hagi.Merge` | Step-0 equivalence of the Hadamard mixer merge: head pre-rotation `W' = W Qᵀ` gives `W' *ᵥ (Q *ᵥ x) = W *ᵥ x`; the concat head sums the experts' logits; orthonormal mixers preserve the dot product — information-neutral. **Two scales, do not mix**: `√n` = mixer orthonormality scale, `1/n` = logit_scale identity (the temperature-correction fix `74e7d30`). |
| `Hagi.Ternary` | Ternary quantization (`scripts/dsv4_experts.py`): 5 trits pack injectively into a byte (`3⁵ = 243 ≤ 256`); nearest-grid rounding on the ternary `{-1,0,+1}` and int4 `±7` grids has error ≤ half a step; the LS grid scale `∑qx/∑q²` is squared-error-optimal at a fixed pattern (normal equations) — the closed form behind “LS scales instead of amax”. |
| `Hagi.ErrorProp` | Telescopic error accumulation of the sequential compression pass (README "telescopic fitting"): `δ_{l+1} = J_l δ_l + r_l` with `‖J_l‖ ≤ α` gives `‖δ_L‖ ≤ α^L‖δ₀‖ + ρ Σ αⁱ`; for the measured `α ≤ 1` this is the Σ-accumulation of expected error. The second-moment version: under residual orthogonality, `‖δ_L‖² ≤ α^(2L)‖δ₀‖² + Σ w_l ρ_l²` with `w_l = Π_{k>l} α_k²` — the layer-weighted “waterfilling” objective for bit allocation. |
| `Hagi.Lift` | The parent-preserving ternary lift `Q(π/2)` of the recursive F3 tree (`ParentPreservingTernaryLift`, merge.py): orthogonal, fixes the diagonal `(1,1,1)` pointwise — lifting three identical parent copies is the identity, the property that makes tree depth meaningful; the leaf subspace (sibling differences) is invariant; the root-mode cortex (writing one value to all leaves) preserves leaf equality — the identity invariant survives the cortex at init. |
| `Hagi.Ridge` | The W2 re-solve of the terni4 recipe (`dsv4_refit_experts.py`, `ridge_solve_guarded`): the ridge objective `‖Xw−y‖²+λ‖w‖²` and **`ridge_optimal`** — any solution of the normal equations `Xᵀ(Xw−y)+λw=0` is a global minimizer (complete-the-square; the pinv guard is about existence, not optimality). This is why the pre-quantization re-solve is safe: it provably extracts everything the quantized upstream can explain, leaving only fresh residual for the telescopic error budget. |
| `Hagi.Select` | **The theory of leaf selection.** (1) `meanBound_greedy`: adding a leaf not worse than the pool mean never raises the mean-CE bound — the bound is monotone in pool size and never certifies pruning. (2) `selection_hurts` (counterexample): ranking by standalone CE can strictly degrade the ensemble — leaf B (±log 8) beats leaf C (±log 2) standalone but loses in ensemble with a fixed partner; the standalone rank and the ensemble contribution are uncorrelated, and anti-correlated in the divergent-leaf regime. **Prescription**: the growth trigger must rank pool candidates by the *ensemble* criterion (merge and measure), not standalone CE. |
| `Hagi.Mix` | **The invisibility condition for a post-concat mixer.** `mixed_invisible`: a low-rank leaf-mixing Q (leaf a reads `∑_b Q a b • h_b` through head `W_a`) is *logit-invisible* — merged logits equal the plain ensemble mean — iff the column sums reproduce the heads (`∀ b, ∑_a Q a b • W_a = W_b`; the shared-head case: column sums = 1, the `parentPreservingQ` analogue in the logit regime). **Prescription**: a mixer after concat is safe iff it acts where the heads agree (unit column sums); anything else moves mass between leaves — the divergent-leaf regime of `Hagi.Select` where the mixer must be trained, not trusted. |
| `Hagi.KVWater` | **Waterfilling for the KV pyramid.** `waterfilling_bound`: among all allocations of a fixed budget, the total KV residual `∑ c_i·exp(−κ b_i)` is minimized exactly at equalized marginal residuals (`c_i·exp(−κ b*_i) = λ`) — the exponential tangent bound. **Prescription**: bits grow *logarithmically* in sensitivity, `b* i − b* j = (log c_i − log c_j)/κ` — rank KV positions by `log(mass·‖v‖)` and set the water level λ from the budget; the naive "bits ∝ p·‖v‖" is wrong (the exponent drives the allocation). No sweeps needed. |
| `Hagi.Ambig` | **Saturation anchors.** `lse_shift` (shift-invariance) and `consensus_no_gain`: when children are shifts of one another, the merged CE *equals* the shared child's CE — consensus is the exact zero of the ensemble gain; every bit of gain above zero is Jensen-gap disagreement. **Prescription for the τ-trigger**: expected next-leaf gain ~ (pairwise spread)²/N; stop when (spread)²/(N(N+1)) < ε² with ε = 0.0021 (the measured floor) — τ becomes a computable rate, not a magic constant. |
| `Hagi.Grow` | **The FGD ε-criterion as the formal GROW trigger** (arXiv 2606.16926, Thm 3.1, translated into the ladder). The certified residual is the mean-CE bound (`ensemble_ce_le_mean_general`); the certified gain of a candidate leaf is `certifiedGain N M c = (M − c)/(N+1)` — computable before the step, exactly like FGD's `U_t`. `certifiedGain_monotone`: bound-ranking by standalone CE is certified (the FGD "refine by the upper bound" step); `grow_epsilon_stop`: if the *best* candidate certifies < ε, *every* candidate does — the GROW axis is certified-exhausted and only the EXHAUSTED axis (change data/leaf kind — no FGD analogue) remains; `certifiedGain_positive`: a candidate beating the pool mean moves the certificate. **Honest divergence**: FGD+PL gives global optimality; our lse-Jensen certifies the mean of the leaves only — the ε-stop certifies the *certificate*, not the model. **Prescription**: replace the empirical SATURATED verdict with `certifiedGain best < ε` (ε = 0.0021 floor), and keep pool choice on the ensemble measurement (`selection_hurts`). |
| `Hagi.GapLaw` | **The local law of the Jensen gap — exact form.** `twoGap p d = ½·log ∑_u ∑_v p_u p_v exp(d_u − d_v)` — the gap of a leaf pair as the MGF of their logit difference under the softmax measure `p` at the midpoint; `twoGap_cosh`: the sinh part cancels by (u,v)↔(v,u) symmetry — the gap is a *weighted cosh sum*; `twoGap_nonneg` + `twoGap_zero_iff` (zero ⟺ shift-consensus — the two-point `consensus_no_gain`); `pairVarEq`: `E[(d_u−d_v)²] = 2·Var_p(d)` — the exact quadratic-law normalization (`Gap ≈ ½·Var_p(d) = ½·Tr[H·Cov]`, no third-derivative error in the *exact* form). **Prescription**: compute the gap BEFORE the merge — one forward per leaf, the pooled softmax, then `∑ p_u p_v cosh(d_u − d_v)`; the complementary-child criterion is low cross-covariance of `d` (the `selection_hurts` regime, from the law's viewpoint); exchangeable rate law `Gap(N) ≈ G∞(1−1/N)` → stop at `G∞/N² < ε` (derived SATURATED, replaces TOL_GAP). |
| `Hagi.RealF3` | **The real 6×6 lift of F₃ (production bridge).** `interleave3` — the branch-major (re,im)-pair injection ℂ³ → ℝ⁶ (the exact `branch_major_pair_interleaved` layout of `_f3_real_column_matrix`); `interleave_norm` — the injection is an isometry (‖φz‖² = Σ|z_a|²); `interleave_char_mul` — the conjugation identity: the real character matrix (the DFT block entries `reBlock(χ₃(−a·c))` of the production R) applied to φz equals φ of the complex character action — the real matrix *is* the transported basis change. The orthogonality of the digest-pinned R follows from the block algebra + character sums (documented; the formal block computation is the next step of the module). **Prescription**: no code change — the formal side now certifies what the digests pin: the production transform is the character action in the interleaved order, not an ad-hoc matrix. |
| `Hagi.Element` | **The element redesign theory (go/no-go before GPU).** `residualLeaf E₀ A B = E₀ + A*B` — the shared-base + low-rank residual leaf; `residualLeaf_zero` — rank-0 deltas are *definitionally* the base: the redesign is a safe step-0 lift (start from pretrained tables, lose nothing at init); `delta_rank_le` / `delta_exact_rank_bound` — any exact rank-r factorization has rank ≤ r, so the observed deltas ΔE_i are exactly representable iff `rank ΔE_i ≤ r` — the go/no-go test is a *rank measurement on checkpoints*, not a training run (the BTX failure 10.10→10.36 is the hint the deltas are high-rank); `params_count` — the budget: N leaves cost V·d + N·r(V+d) vs N·V·d, saving real iff r ≪ d at V ≫ d. Eckart–Young (best rank-r error = σ_{r+1}) is not in Mathlib yet — the honest gap, documented; the practical test is the measured spectrum σ_{r+1}/σ_1. |
| `Hagi.Joint` | **The joint step theory (LR law + the slimpajama catastrophe).** `jointStep_conflict_regression`: a corpus whose gradient *conflicts* with the mixture direction MUST regress at every small LR (window `0 < lr < 2|⟨gc,g⟩|/(L‖g‖²)`) — first-order geometry, not an optimization accident; `jointStep_regression_bound`: any per-corpus regression ≤ `|lr|·‖gc‖‖g‖ + (L/2)lr²‖g‖²` — linear in LR (the derived joint-LR schedule `lr ≤ ε/(‖gc‖‖g‖ + (L/2)‖g‖²)`); `trustRegion_bound`: a proximal step within radius R regresses no corpus more than `‖gc‖R + (L/2)R²` — the ridge-to-prior cure, geometric, direction-free. **Prescription**: per-corpus guard with the derived bound (not the empirical 0.001); the slimpajama regime needs the proximal form, not a smaller LR. |
| `Hagi.GenCycle` | **The generational cycle and the death of recursion.** `genMean_assoc` — the hierarchical mean-of-means equals the flat mean (the formal ground of the round-21 merge-granularity fix; the 3×-identical test is an instance); `genMean_compound` — the linear compounding law (k cycles improve the mean by ≥ k·c); `genGap_decay` — the death law: if sibling disagreement evolves `G_{t+1} ≤ ρG_t + D` (ρ<1), then `G_t ≤ ρ^t G₀ + D(1−ρ^t)/(1−ρ)` — stationary disagreement `D/(1−ρ)`. **Prescription**: the generational verdict = the same twoGap ε-criterion as the ladder level (measure the sibling disagreement of fresh leaves; alive while ≥ ε); when the fixed point falls under ε, only the data axis (EXHAUSTED: change the corpus mixture D) remains. |
| `Hagi.Concat` | The concat==child invariant and the temperature correction (commit `74e7d30`, `test_merge_invariants.py`): the concat head of N identical children sums the block contributions (`n • (W*ᵥx)`); the identity scale is forced to be `1/n` (the `logit_scale = child/n` fix — the old `/√N` provably breaks the invariant); rescaled logits (`c ≠ 1`) reproduce the softmax only on constant logits. **Ensemble theorem**: `CE(mean logits) ≤ mean CE` for ALL N (`lse_mean_le_mean_lse` via N-factor AM-GM/Hölder + `ensemble_ce_le_mean_general`): merged-at-1/n beats the average child for any pool size, and CAN beat every child (complementary experts), so "concat cannot beat the best leaf" is false in general. |
| `Hagi.Attention` | Softmax-weighted error damping — the principle of the KV precision pyramid (README "Target KV design"): an error entering the attention output weighted by `pᵢ` contributes at most `max‖eᵢ‖`. |
