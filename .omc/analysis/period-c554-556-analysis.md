## (а) Унификация-эра: одна адаптерная машина на весь жизненный цикл

Главный структурный итог витка: контуры СЛИТЫ. Exact-bypass
(символьный) и адаптерный остаток (нейронный) больше не параллельные
машины — это один адаптерный контур:

- **Growth** (C532–C547): rank-1 адаптеры, 3 оси роста —
  механизм добавления знания.
- **Continual** (C548–C550): изоляция forgetA = 0 — механизм
  сохранения знания.
- **Compression** (C555): Матрёшка-merge, bounded 2·k·d —
  механизм упаковки знания; k<d теряет (негативы certified).
- **Distill** (C556): символьное → нейронное (θ(c)) — механизм
  ПЕРЕНОСА знания между контурами, lossless.

Полная алгебра жизненного цикла знания (добавь / сохрани / сожми /
перенеси) теперь certified в одной машине. Ветвлений 113 → 0 —
структурное доказательство слияния, не декларация: весь корпус
проходит одним matmal-путём (кластеры — адаптерами, остаток —
замороженной головой).
