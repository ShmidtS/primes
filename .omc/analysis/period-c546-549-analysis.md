Roadmap-2 из C543–C545 («мини-HAGI полный цикл») перевыполнен:
не один цикл, а ИТЕРАТИВНЫЙ цикл с сертифицированными свойствами.

1. **Цикл находит примитивы** — OE-поиск по пространству
   семей; C547: 94.7→99.1%, C549: 54.9→93.8% (7 итераций).
2. **Строит из них новые** — `coversPrim`: каждый следующий

   НЕ декларация, а негатив: контрпримеры показывают, что без
   найденных примитивов конструкция не работает (прецедент
   негативной сертификации C545 сохранён).
3. **Монотонно растит покрытие** — `coverage_append_monotone`:
   покрытие семейства только расширяется, откат невозможен
   теоремой, не дисциплиной.
4. **Самостоп по EB-гейту** — остановка не по бюджету, а по
   сертифицированному критерию (entropy-budget); C549-прогон
   остановился сам на 93.8%.
5. **Не забывает** — forgetA = 0 структурно (наследие ISO
   C544 встроено в цикл, не добавлено снаружи).

Это первый виток серии, где «selfimproving» в названии
репозитория соответствует теореме о системе, а не о частях:
