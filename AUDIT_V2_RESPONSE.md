## 2. Принятые меры (этот виток)

- **ReachLint.py** (пункт 4): воспроизводимая метрика достижимости:
  394 модуля, 3301 декларация, cross-used 19.8%, острова 39.1%
  (оценка снизу: неявные использования не считаются).
  Запуск: `python scripts/ReachLint.py [--islands]`.
  Информационная (не блокирует CI) — становится базовой
  линией для Фаз 1–4.
- **frob_minkowski' удалён** (пункт 6, единственный
  подтверждённый дословный дубль; Freeze --update).

## 3. Дорожная карта (принята, приоритет = (Impact+Risk)×(6−Effort))

- Фаза 0 ✅: Freeze-сетка + ReachLint-базовая линия.
- Фаза 1 (дешёво, без изменения смысла): External → отдельный
  пакет; TopLevel/ArchitectureTheorem — переименование по
  содержимому; ручная проверка 24 «групп дублей» (уже начата:
  2 из проверенных — не дубли); точечные импорты.
- Фаза 2 (семантика): Machine с живыми измерениями на шаге
  (ReferenceMachine/MachineBridge — прототип), ОДИН Contract
  (CertifiedTransitionV3 + StepContract-моноид), одна
  топ-теорема = certified_loop ⊕ trajectory_convergence ⊕
  δ-бухгалтерия (anytime-слой готов).
- Фаза 3 (ядра): FinDist/PMF, Chord→Hoeffding→Azuma→Freedman
  цепочка, единое InfoTheory/Thermo.
- Фаза 4: острова — адаптер к Contract или Lab.

## 5. С чем НЕ согласны

- «Тавтология» (категория B): телескоп Ляпунова — это ядро
  контракта, а не претензия на теорему об обучении; условность
  зафиксирована в самом README («three layers, honest status»).
  Тем не менее претензия аудита «условные теоремы не должны
  выглядеть как безусловные» — принята: canonical-имена V3
  делают условность видимой в сигнатуре.
- AIF/Omni-«фасады»: это документированные мосты-наброски, не
  заявления о полной теории; принимается решение Фазы 4:
  без адаптера к Contract — в Lab.
